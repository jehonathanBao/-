Read these first when a task spans multiple layers or touches product behavior.

- [`/PRODUCT.md`](/PRODUCT.md): product purpose, UX tone, and explicit read-only boundaries.
- [`/AGENTS.md`](/AGENTS.md): repo-level safety defaults and required validation habits.
- [`/docs/workspace_policy.md`](/docs/workspace_policy.md): Rust repo is the execution target unless a task explicitly says otherwise.
- [`/docs/server-deployment-runbook.md`](/docs/server-deployment-runbook.md): live deployment path, nginx/public port model, and post-deploy checks.
- [`/docs/runbook/contract-whale-monitor.md`](/docs/runbook/contract-whale-monitor.md): contract whale semantics, storage layers, retention, and operator expectations.

When a task changes project behavior, add any new durable convention to the most relevant package index instead of burying it in a plan note.
