# 科技金融监控终端 UI

用户已确认深色专业金融终端方向，并补充要求动态效果。本文记录同一方案，不扩展后端功能。

- 石墨黑背景、冷青色强调、统一冷灰层级，保留风险/涨跌语义色；中文正文可读，行情数字等宽。
- 侧栏按总览、合约市场、现货市场、信号中心、工作区分组，保留全部既有入口。窄屏换行导航，键盘可达。
- 首页为标题与同步控件、状态指标、真实 BTC 价格走势与资金脉冲、统一事件流、链路状态。移除装饰性 AI 神经网络画面；不以模拟曲线冒充行情。
- 合约页强化品种、主评级和主力行为线索；添加已加载事件的价格轨迹，明确“事件触发价，非连续行情”，不新增数据采集请求。证据、历史分页、详情入口全部保留。
- 动态限于页面轻量入场、价格/指标更新提示、事件高亮、状态呼吸和图表交互。支持手动关闭动态；后台和系统 reduced-motion 停用。禁止循环计算装饰粒子。
- 行情/错误/空态来自现有接口；不改变 canonical 评级、过滤门槛、通知门控、缓存或交易安全边界，不新增执行按钮。
- 沿用 React 19、Vite 7、Tailwind 3、Heroicons，无新增依赖。只修改本地 UI，未经另行要求不提交、部署或发送通知。
- 验证：新增导航/动态/图表测试，现有前端全量测试，生产构建，桌面与移动端截图和导航/筛选/空态检查。
