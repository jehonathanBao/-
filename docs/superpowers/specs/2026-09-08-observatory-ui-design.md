# 动态观测仪表台

按用户提供的白色科研终端参考图，迭代现有 React/Vite 监控界面。保留顶部导航、所有原有路由、读数、筛选、详情和通知权限。以纸白、灰绿细线、石墨文字为底，黄绿品牌标记，青绿/玫红表达买卖方向。

总览及 BTC/ETH 合约页共用四组图形：主动成交地形、交易所弦图、旋转证据结构、方向关系图。地形每层为一个已加载 K 线或事件窗口，双峰高度来自买卖量，宽度仅为显示用核函数。事件窗口不相加为全市场区间成交量。弦图表示来源与方向的事件计数；关系图仅表示方向分组，不暗示钱包、资金流转或因果。证据结构旁的评级/风险分/质量来自原始事件，缺失显示破折号。

地形支持样本探针，方向图支持筛选，几何相机支持冻结。CSS 动效与 25fps 上限的 SVG 相机均遵守全局开关、系统 reduced motion 和后台暂停；相机离开视口也暂停。显示变换不改变底层数据。沿用分页和有界样本，新增图形无额外 API 请求。

开发环境 `/design-preview` 使用标注清楚的固定演示数据，可切换缺失状态；正式构建不包含该路由与演示样本。真实页面无数据时显示空坐标与缺失读数。

验收：测试数据缺失/不合法/跨币种、评级保持、去重和上限、探针、方向筛选、相机清理；运行前端现有测试与构建；浏览器检查宽屏和手机布局、动效开关与真实空数据页面。
