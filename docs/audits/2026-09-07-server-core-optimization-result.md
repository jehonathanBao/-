## 已实现、待最终验收的修复

1. 统一事件重要性为 S/A/B/C；预测成熟度、行为证据强度另行表示。事件没有足够证据时显示未评级，不能由预测 S、旧信号等级或当前页面样本排名补成 S。
2. 正常配置的单一 Binance 来源不再因固定双交易所要求而永远达不到 A/S；依旧要求可靠基线、有效价格、足够市场影响及数据质量。现货、OI 和重复来源不能冒充额外交易所。
3. 修正空头收益重复变号、未来价格进入事件参考、重复样本增加置信度、缺失结果仍显示满覆盖率等问题。新校准版本隔离旧结果，保留原历史记录。
4. 事件生成时计算真实微波动及同时点普通现货成交证据，并保存后再展示。价格事后走对不再自动证明主力建仓；没有身份数据时参与者归属保持未知。
5. 轨迹至少需要三个独立时点、持续一分钟，才可形成持续方向假设。新增 1/5/15/60 分钟公共净成交持续性观察，要求可用历史基线、覆盖率和方向一致性；候选暂时只展示，不发送新类型外部通知。
6. 按 Binance 路由要求分别连接市场成交和公开盘口，清算连接保留心跳回复并披露连接状态。清算数据明确为抽样，不解释成全市场清算总额。
7. 校准循环降低无变化重复计算，复用触发时冻结的预测，按到期时间更新结果。评级版本升级保留发送去重，重启前队列信号不补发。
8. 集中审查的四项问题已修复：相反方向/行为分开编号，同一事件只用一个冻结时间锚点；持续性信号的持仓和资金费率取自已结束窗口；缺失分钟不能反转已确认的持续方向；缺失价格端点保持未知，不当作零涨跌。
9. 回归定位的持仓/资金费率读取问题：保留同一分钟内的真实快照时间；原始快照过期后，分钟汇总只能按分钟结束时间使用，不能提前到分钟开始，也不能覆盖仍存在的真实快照。

以上改善的是可解释性与已复现的正确性问题，不构成主力身份识别保证，也尚不能宣称实盘预测精度提升；精度需要后续真实独立样本评估。
